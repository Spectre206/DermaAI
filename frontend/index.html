Lab Project Features

Bridging the gap between Computer Vision and Dermatology.

Dermoscopic Analysis

Designed specifically to analyze dermoscopic (magnified) images of skin lesions for pattern recognition.

Explainable AI

Uses Grad-CAM heatmaps to visualize which pixels influenced the model's decision, adding transparency.

Doctor Referral

If a risk is detected, the system recommends specialists in your area (e.g., Peshawar) for a proper diagnosis.

AES-256 Encryption

Patient symptoms and sensitive medical data are encrypted in the database using industry-standard AES-256 for maximum privacy.
